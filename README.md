# Computer Networks Lab Record

A collection of 13 Computer Networks laboratory experiments, with experiment reports, Cisco Packet Tracer activities, and socket-programming examples.

## Experiments

| No. | Experiment | Materials |
| --- | --- | --- |
| 01 | Network Cables and Crimping | PDF report, Packet Tracer file |
| 02 | Basic Network Commands | PDF report, Packet Tracer file |
| 03 | Network Devices Study and Installation | PDF report, Packet Tracer file |
| 04 | IP Addressing and Subnet Configuration | PDF report, Packet Tracer file |
| 05 | Connecting Computers in a Local Area Network | PDF report, Packet Tracer file |
| 06 | Router Configuration Using Packet Tracer | PDF report, Packet Tracer file |
| 07 | Peer-to-Peer LAN Using a Switch and Router | PDF report, Packet Tracer file |
| 08 | Network Address Translation (NAT) | PDF report, Packet Tracer file |
| 09 | Routing Protocol Simulation | PDF report, Packet Tracer file |
| 10 | Client-Server Communication with TCP and UDP | PDF report, Packet Tracer file, Python socket examples |
| 11 | Socket Programming and Client-Server Model | PDF report, Python socket examples |
| 12 | Network Simulators and Analysis Tools | PDF report, Packet Tracer file |
| 13 | DHCP Server Implementation | PDF report, Packet Tracer file |

Each experiment is stored in its own numbered folder. The folder contains the corresponding `Experiment_XX.pdf` report and, where available, its `.pkt` activity and source code.

## Working with the files

- Open a report PDF with any PDF reader.
- Open `.pkt` files with Cisco Packet Tracer.
- Run the Python socket examples with Python 3. For client/server exercises, start the server before the client and make sure both use the same host and port. Some examples may require running the client and server in separate terminals.

## Notes

- The reports are provided as a lab-record reference. Add your own observations, outputs, and instructor-required details where appropriate.
- Packet Tracer activities are included only for experiments that have a `.pkt` file in the folder.
